# Test 10 — HUD

**Skill area:** UI / React

## Prompt

> Show a health bar and score counter overlaid on the game.

## Pass criteria

- Uses `HologyScene` with a React HUD layered over the game (DOM/CSS overlay).
- Reactive state via signals / React hooks reading from a service.

## Fail signals

- DOM hand-wired outside the framework, or drawing UI into the Three.js scene instead of an HTML overlay.
