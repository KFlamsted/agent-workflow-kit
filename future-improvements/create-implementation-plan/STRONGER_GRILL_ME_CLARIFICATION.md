# Stronger Grill-Me Clarification

Potential addition to the clarification process in `skills/create-implementation-plan/SKILL.md` and `agents/task-planner.txt`:

```md
Be persistent rather than deferential during clarification: probe vague terms, examples, implied workflows, and unstated edge cases. If an answer uses subjective language such as "simple", "normal", "fast", or "user-friendly", ask what observable behavior or acceptance criterion it implies.
```

This would make the clarification phase more probing. It is intentionally kept as a future improvement until its effect on question volume and planning flow has been evaluated.
